Tutorial singkat pengoperasian FO Network Mapper

Ikuti 3 langkah praktis ini untuk memetakan jaringan kabel fiber optic dalam hitungan menit:
1

Tentukan Titik Tiang / ODP / Gedung

Klik tombol mode `+ Titik` di panel atas, lalu klik posisi tiang/gedung di peta. Anda juga bisa mengisi koordinat GPS, nama perangkat, dan mengunggah foto dokumentasi fisik.

2

Tarik & Hubungkan Jalur Kabel FO

Klik tombol mode `+ Jalur` lalu klik titik awal dan titik akhir di peta. Atau di Tab Data, klik ikon Rute Hijau 🛣️ di samping nama gedung/titik untuk langsung menyambung kabel!

3

Klik Kabel & Titik di Peta untuk Fitur Lanjutan

Klik garis kabel atau titik closure di peta untuk membuka menu teknis lengkap:
• Tabel Splicing Core: Klik titik Joint Closure / ODP untuk mencatat sambungan core masuk ➔ keluar.
• Sambung Jalur: Lanjutkan tarikan rute dari ujung terakhir.
• Edit Belokan & Relokasi: Menggeser dan meluruskan titik sudut rute jika ada perubahan tiang.
• Lacak Putus (OTDR Fault): Masukkan meter hasil ukur OTDR lapangan untuk mencari titik putus di peta.
• 12 Warna Core: Kelola alokasi tube dan 12 warna core standar TIA/EIA-598.

Mode Geser (Pan)

Navigasi bebas. Geser dan zoom peta tanpa khawatir mengubah atau menghapus data.

Mode + Titik

Klik sembarang tempat di peta untuk menaruh Tiang, ODP, Closure, ODC, atau Gedung.

Mode + Jalur

Klik titik awal dan klik titik-titik berikutnya untuk menggelar tarikan kabel FO baru.

Mode Hapus

Klik langsung tiang atau garis kabel yang ingin dihapus (hanya aktif untuk Super Admin).

Snap Jalan (OSRM)

Saat aktif, tarikan kabel akan otomatis meliuk mengikuti jalan raya, tidak berupa garis lurus kaku.

OTDR Fault Locator

Ketik hasil ukur meter dari alat OTDR, sistem langsung menancapkan marker titik putus kabel di peta.

Tabel Splicing Core (Closure/ODP)

Catat pasangan sambungan kabel masuk ke kabel keluar (Core 1 Kabel A ke Core 1 Kabel B) lengkap dengan status aktif, redaman loss dB, dan ekspor CSV.

12 Warna Core TIA

Pengaturan warna standar internasional (Biru, Oranye, Hijau, dst) per tube dan kapasitas kabel.

Backup JSON & KMZ

Unduh seluruh arsip data untuk dicadangkan (JSON) atau dibuka langsung di Google Earth (KMZ).
